# 🇧🇯 Bénin Tourisme - Découvrez le Bénin Autrement

## 🌍 À propos du projet

**Bénin Tourisme** est une plateforme web moderne dédiée à la promotion du patrimoine touristique, culturel et naturel du Bénin. Notre mission est de faire rayonner les trésors béninois auprès des visiteurs locaux et internationaux.

### ✨ Fonctionnalités principales

- 🏛️ **Découverte des sites touristiques** : Des palais royaux d'Abomey aux maisons sur pilotis de Ganvié
- 🎭 **Agenda culturel** : Festivals, cérémonies vodoun, événements traditionnels
- 🗺️ **Cartes interactives** : Localisation précise des attractions par département
- 📍 **Itinéraires personnalisés** : Créez votre parcours de visite sur mesure
- 🏨 **Hébergements authentiques** : Hôtels, auberges et cases traditionnelles
- 🍲 **Gastronomie locale** : Découvrez les saveurs du terroir béninois
- 📱 **Design responsive** : Accessible sur mobile, tablette et desktop
- 🇫🇷 **Français & langues locales** : Support du Fon, Yoruba et Dendi

### 🗺️ Destinations phares

## 📦 Installation locale

```bash
# Cloner le dépôt
git clone https://github.com/votre-username/benin-tourisme.git

# Installer les dépendances
cd benin-tourisme
npm install

# Lancer en développement
npm run dev

# Construire pour la production
npm run build
---
# Voir la taille du build
du -sh dist/

# Tester en local
npm run preview

# Déployer (exemple avec Vercel)
vercel --prod

# Ou Netlify
netlify deploy --prod --dir=dist
---
